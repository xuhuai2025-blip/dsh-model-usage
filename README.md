# 模型用量

DSH 原生左侧栏插件。只读聚合本机**当前 DSH 持久化服务可见的会话**，包括子会话；不是全机流量抓取器，也不是账户余额或订阅额度查询。

## 安装到当前应用

1. 在当前 DSH 中打开「插件」，选择添加／安装本地插件。
2. 选择发布包或本插件的已构建目录，安装并启用。包名保留 `@local/dsh-model-usage`。本插件是 MIT 授权的第三方插件，不属于宿主内置功能。
3. 左侧栏出现「模型用量」。如客户端尚未加载，刷新当前 GUI；如果插件管理明确提示需要重启，先等待当前任务结束再按提示重启。

重新安装或重新构建后，通过插件管理停用／启用插件，并刷新宿主页面；如宿主提示重启则按提示处理。没有源码构建 watcher，不承诺保存源码后自动更新。构建产物使用内容指纹文件名，避免桌面端 ESM 和浏览器缓存继续加载旧版本；`dist/` 只保留当前生成的四个运行文件。

## 页面功能

- 今日、近 7 个自然日、本月、全部时间，统一 Asia/Shanghai 时区。
- 极简首页：总 Token、API 估算成本、请求次数等紧凑指标；模型用量饼图支持 Token／成本切换。
- 按精确模型 ID 聚合，同一 OpenAI 模型的 API 与 Codex 订阅来源只显示一项；Token、成本与请求累加，会话 ID 去重，原始来源保留在聚合元数据中。不删除日志，也不合并不同型号。
- 页面只保留指标、饼图和简洁模型明细；不显示详情入口、说明段落、用量分类或单价表。数据缺失和部分估算仅保留在相应数字的悬停提示中，网络错误仍即时显示。
- 当前区间聚合 CSV 导出，不含提示词、回复或工具原文。面板可见时每 60 秒刷新，支持手动刷新。
- 模型会话数可能重叠，不能简单求和。调用次数是**有用量回执的请求结算**，不是用户消息数；报告用量的失败／重试也可能计入。

## 价格和成本口径

所有费用均为 **USD API 等价估算**，不是实际扣费、订阅账单或应付余额。

价格快照核验日：**2026-11-03**。只内置已从官方页面核验的型号，不对未知型号做模糊匹配或套用“相近模型”的价格。

- [OpenAI 官方价格](https://developers.openai.com/api/docs/pricing)：Standard 文本价。GPT-6.1 Sol 每百万未缓存输入 / 输出 / 缓存读取分别为 **$2 / $10 / $0.10**；单次总输入（含缓存）超过 272,000 时按长上下文 **$4 / $15 / $0.20** 计价。
- [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)：DeepSeek Flash 峰值每百万未缓存输入 / 输出 / 缓存读取分别为 **$0.30 / $1.20 / $0.006**。第一版统一用峰值价做上限估算，**未应用低峰半价**，通常高于实际标准 API 费用。
- [Claude 官方价格](https://platform.claude.com/docs/en/about-claude/pricing)：内置部分当前已核验型号。缓存写入 TTL 未知时，对该次费用显示未定价，不猜测。
- [MiniMax 官方价格](https://platform.minimax.io/docs/pricing/overview)：MiniMax‑M3.1‑Flash 每百万输入／输出／缓存读取为 **$0.15／$0.60／$0.015**，使用本型号独立价格，不套用 M3。另支持 MiniMax‑M3 Standard 当前永久五折价及 >512k 输入的长上下文档位。
- [MiniMax 国内站价格](https://platform.minimax.cn/docs/pricing/overview)：M3.1‑Flash 为 **¥1／¥4／¥0.10**。本插件为统一 USD 等价成本采用国际站美元价，不将人民币直接相加，也不使用虚构汇率，因此不等同于国内站实际扣费。

历史调用也按当前快照折算，并非按调用当日历史价格恢复。未自动联网更新价格，更新官方价格需修改 `prices.js` 并重新加载插件。也不根据当前所选模型覆盖历史路由。

公式：`未缓存输入 × 对应单价 + 输出 × 对应单价 + 缓存读取 × 对应单价 + 缓存写入 × 对应单价`，所有 Token 单价以每百万计。

未知价格、未知缓存写入档位或不可证明的用量分类不按零处理：显示未定价；只有部分请求可定价时显示部分估算，成本占比的分母只包含可定价费用。全部未定价时总成本为空值，而不是 $0。

不含工具调用、图像生成、区域附加费、税费、订阅费用、特殊服务档位折扣／加价。仅覆盖日志中有用量回执的对话请求：**自动标题等没有用量日志的额外请求无法统计**。

## 数据正确性与隐私

后端通过 DSH `sessionPersistence.list / open(id, 'read') / read / close` 读取，不修改、迁移发布或重写聊天记录，不读取 API Key 或浏览器凭据。

- DSH `inputTokens` 是未缓存输入，缓存读写为独立桶；合计四桶相加。推理 Token 已包含在输出中，不再叠加。
- 同 turn / step 的重复结算替换旧样本；`llm/retry-started` 后新样本单独累计。
- 子会话使用存储服务给出的 `inheritedEventCount` 排除继承历史，只计算本会话新增请求，避免 fork 重复计费。
- 零缓存桶可能被适配器省略：只有精确总量能证明缺失桶为零时才安全估算；否则不猜测成本。
- 只缓存数值、时间与模型路由。不把原文发送给页面、不写额外账本、不新增模型调用。重启后从原有日志重建。
- 缓存按会话不透明 revision 更新；生成中请求要结算且进入持久化服务后才显示，可能短暂滞后。
- 坏日志或暂时无法读取的会话独立警示，不伪装成完整统计；全部读取失败返回错误而不是零。
- 接口 `/api/model-usage` 由 DSH connection 的认证 owner 路由保护，不另开监听端口。

## 开发与验证

要求 Node.js >=22.14、pnpm 11 和兼容 `package.json` 声明版本的 DSH。插件独立开发，不依赖宿主 checkout。在插件根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm pack
```

构建与测试只用 Node.js 标准库，无第三方运行时依赖或开发依赖。React 与 slots 由 DSH 提供，不重复打包；锁文件保留包管理器的空依赖图。源码：`core.js` 聚合和只读缓存、`prices.js` 价格快照、`index.js` 认证接口、`panel.js` React 面板。浏览器和服务端内容寻址产物位于 `dist/`，构建会清除其中过期的已知 hash 产物，不依赖本机绝对路径。

测试位于 `tests/`，使用合成事件，不修改真实会话。`prepack` 自动重建并执行测试；发布白名单只包含运行文件、语言资源、图标和文档。自动化测试不代表在宿主中完成界面验收。
